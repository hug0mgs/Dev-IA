## 3. Plano de Ação: Como subir de nível nos 3 piores requisitos

**1. Implantar software em ambientes on-premise e cloud (De nota 0 para 1 ou 2)**
* **O que preciso construir:** Preciso pegar um projeto local simples (como uma API em Python/Node) que eu já tenha feito e realizar o deploy gratuito em um provedor de nuvem, como AWS (EC2, Elastic Beanstalk), Render ou Heroku, utilizando a ajuda do agente para guiar os comandos e configurações iniciais.

**2. Construir pipelines de dados (De nota 1 para 2)**
* **O que preciso construir:** Criar um script prático (ETL) que extraia dados de uma fonte (como uma planilha CSV ou JSON sujo), faça a limpeza e transformação desses dados (ex: converter tipos, tratar nulos) usando Python, e os carregue em um banco de dados local como SQLite. Farei isso com a assistência e explicações do agente.

**3. Integrar APIs de terceiros (De nota 2 para 3)**
* **O que preciso construir:** Preciso construir uma integração com uma API REST externa (como de clima, correios ou pagamentos simples) 100% sozinho. O objetivo é escrever o código da requisição, tratar os dados do JSON retornado e exibir na tela sem usar prompts do agente, garantindo que eu saiba explicar cada linha de código implementada. *(Nota: a mesma lógica poderia ser aplicada a "Otimizar consultas", que também tirou nota 2).*

**O que acho que já vai bem:** 
Tenho um nível de autonomia muito forte (nota 3) em áreas críticas de infraestrutura e conectividade. O fato de já conseguir desenvolver conectores customizados, configurar/orquestrar contêineres e depurar infraestrutura de rede por conta própria demonstra uma ótima base técnica prática.

**O que ainda não vai tão bem:** 
A parte de deploy (nuvem/on-premise) é meu ponto mais fraco no momento, seguida pelo fluxo de engenharia de dados (pipelines). São duas áreas essenciais para um *Forward Deployed Engineer*, já que o objetivo da vaga é colocar o código para rodar no ambiente do cliente. Focarei o plano de ação nessas áreas.
